# Sandbox: главное меню и состояние карты через SignalR

При запуске появляются три кнопки: **Create game**, **Connect**, **Exit**.

- **Create game** загружает `Default_Map` в BoardState и передаёт снимок карты
  через SignalR. Сервер создаёт сессию, сохраняет карту и добавляет создателя
  как первого игрока. После ответа открывается карта с кодом игры.
- **Connect** открывает ввод кода. Введите 6 символов, нажмите Connect или Enter.
  Клиент получает карту сервера и строит изображение из неё, не читая локальные CSV.
- **Exit** закрывает окно. **Main menu** на карте отключает игрока и возвращает меню.
  Escape возвращает в меню; из главного меню — закрывает приложение.

Ошибки подключения показываются на экране, окно продолжает работать.
Сетевые обращения имеют таймауты; графические объекты создаются только в Game1.Update.

## Запуск в PowerShell

Нужны .NET SDK 8 или новее, Docker Desktop с Linux containers.
Из корня board-game:

```powershell
docker compose up -d --build
cd Sandbox
dotnet run
```

Откройте второй терминал в Sandbox и снова выполните `dotnet run`.
В первом окне выберите Create game, во втором — Connect и введите код.

## Что передаётся

BoardSnapshot сохраняет все поля текущего BoardState: гексы и их числа/местность,
регионы, опустынивание, узлы и флаги, племена, требования путей, счётчики,
заблокированные пути и позиции врагов. Для сети словари превращаются в массивы.
После получения создаётся новый BoardState, затем строится геометрия.

Состояние находится в GameSession.Board и хранится в оперативной памяти.
После выхода последнего игрока сессия удаляется. Перезапуск сервера тоже удаляет игры.
